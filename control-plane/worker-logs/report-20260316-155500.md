## Result: CRITICAL BUG FIXED
**Root Cause Identified:** OILimits.getGlobalOI() returns values in USDT format (6 decimals), but both ProtocolStats.tsx and Vault.tsx APY calculations treated these values as WAD format (18 decimals), making the calculated APY 1e12 times smaller than correct.

**Technical Fix Applied:**
- Added OI conversion in ProtocolStats.tsx: `totalOIInWad = totalOIRaw * BigInt(1e12)`  
- Added OI conversion in Vault.tsx: `globalOIInWad = globalOI * BigInt(1e12)`
- Fixed calculation to use WAD-converted OI in projected APY formula
