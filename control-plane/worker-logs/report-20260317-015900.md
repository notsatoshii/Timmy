## Actual bugs found and fixed

### 1. useTradeHistory.ts — BigInt(float) RangeError
- **Root cause:** `BigInt(Date.now() / 1000 - 3600)` produces a float (e.g. 1773708686.915) which cannot convert to BigInt
- **Fix:** Wrapped all 4 timestamp calculations in `Math.floor()`
- **Impact:** Would cause crash when Trade History component mounts

### 2. ErrorBoundary.tsx — Hidden error details
- **Root cause:** Error details gated behind `process.env.NODE_ENV === 'development'` which is false in production builds
- **Fix:** Always show error details so debugging is possible in the demo build
